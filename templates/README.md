# Templates

Genbrugelige templates til hurtig projektopstart.

## Tilgængelige Templates

Hver template-mappe indeholder en komplet struktur klar til brug.

### Sådan Bruger Du en Template

1. Kopier template-mappen til `projects/`
2. Omdøb til dit projektnavn
3. Tilpas README og konfigurationsfiler
4. Start udvikling!

## Template Kategorier

- **python-cli/** - Python CLI applikation
- **web-app/** - Web applikation (React/Vue)
- **automation-script/** - Automatiseringsscript
- **data-analysis/** - Data analyse projekt
- **api-service/** - REST API service

Tilføj dine egne templates efterhånden som du udvikler mønstre du genbruger!
