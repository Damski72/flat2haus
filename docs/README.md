# Dokumentation

Personlig dokumentation, notater og læringResourcer.

## Indhold

- **guides/** - How-to guides og tutorials
- **notes/** - Løbende notater og idéer
- **references/** - Hurtig reference sheets
- **learning/** - Læring og uddannelse notater

## Organisering

Brug klar navngivning:
- `YYYY-MM-DD-emne.md` for daglige notater
- `emne-guide.md` for guides
- `emne-reference.md` for quick references

## Tips

- Link til relevante projekter
- Tag filer med keywords i frontmatter
- Gennemgå og konsolidér jævnligt
